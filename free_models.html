Cursor setup with Groq Llama 3.3 70B (30 RPM, 14,400 RPD) for free:

Cursor Settings (Cmd + ,) → Models → Add Model:
  • Model Name: llama-3.3-70b-versatile
  • Base URL: https://api.groq.com/openai/v1
  • API Key: [Free gsk_ key from console.groq.com/keys]

Connecting Claude Code CLI to OpenRouter endpoint:

# Claude Code uses Anthropic-compatible endpoints:
export ANTHROPIC_BASE_URL="https://openrouter.ai/api"
export ANTHROPIC_AUTH_TOKEN="sk-or-v1-YOUR_OPENROUTER_KEY"
export ANTHROPIC_API_KEY=""  # Leave blank for AUTH_TOKEN to work

Calling Groq free endpoint in Codex CLI:

export OPENAI_BASE_URL="https://api.groq.com/openai/v1"
export OPENAI_API_KEY="gsk_YOUR_GROQ_KEY"  # Free key from console.groq.com/keys
codex --model "llama-3.3-70b-versatile"

Calling GLM-5.3 Flash based Ox Alpha (100T/day) in CommandCode CLI:

npm i -g command-code
# 1M context & 100T tokens/day allowance
cmd --model stealth/ox-alpha

Calling free endpoints via official Python OpenAI SDK:

from openai import OpenAI

client = OpenAI(
    base_url="https://api.groq.com/openai/v1",  # No credit card needed
    api_key="gsk_YOUR_KEY",                     # Free from console.groq.com/keys
)

res = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(res.choices[0].message.content)
