OpenRouter

CommandCode.ai

4개 무료 모델

터미널 AI 코딩 에이전트로, 독자적인 taste-1 스타일 학습과 함께 스텔스 프리뷰 모델을 $0 제공합니다.

  • 대표 모델: Ox Alpha (GLM-5.3 Flash 실체), Space Bunny, Glyph Cluster
  • 과금 정책: 무료 플랜에서도 프로모션 기간 동안 $0 제공
  • 요청 한도: Ox Alpha (100T/day 한도 없음), Glyph (100 req/day)
  • 터미널 실행: cmd --model stealth/ox-alpha 즉시 호출
🔗 CommandCode 공식 웹 CLI & Desktop Studio

⚡ 30개 무료 API 제공사 & Base URL 퀵 레퍼런스 (awesome-free-llm-apis 연동)

▼ 클릭하여 열기

신용카드 없이 이메일 가입만으로 무료 키를 발급해주는 30개 검증된 LLM API 프로바이더의 OpenAI 호환 Base URL과 키 발급 링크 목록입니다. Base URL 복사 후 바로 도구에 붙여넣으세요.

제공사 (Provider) 무료 모델 수 신용카드 요구? 최대 컨텍스트 OpenAI 호환 Base URL 추천 베스트 모델 API Key 발급

🛠️ 인기 개발 도구별 1클릭 무료 API 연동 가이드 (Claude Code, Cursor, Codex, OpenCode, Aider)

▼ 클릭하여 열기

Cursor에서 Groq의 초고속 Llama 3.3 70B(30 RPM, 14,400 RPD)를 무료 연동하는 방법:

Cursor Settings (Cmd + ,) → Models → Add Model:
  • Model Name: llama-3.3-70b-versatile
  • Base URL: https://api.groq.com/openai/v1
  • API Key: [console.groq.com/keys 에서 무료 발급받은 gsk_ 키]

Claude Code 터미널에서 OpenRouter 엔드포인트를 연결하여 사용할 때:

# Claude Code는 Anthropic 호환 엔드포인트를 사용합니다:
export ANTHROPIC_BASE_URL="https://openrouter.ai/api"
export ANTHROPIC_AUTH_TOKEN="sk-or-v1-YOUR_OPENROUTER_KEY"
export ANTHROPIC_API_KEY=""  # 비워두어야 AUTH_TOKEN이 작동합니다

Codex CLI에서 Groq 무료 엔드포인트를 호출할 때:

export OPENAI_BASE_URL="https://api.groq.com/openai/v1"
export OPENAI_API_KEY="gsk_YOUR_GROQ_KEY"  # console.groq.com/keys 무료 발급
codex --model "llama-3.3-70b-versatile"

CommandCode CLI에서 GLM-5.3 Flash 기반 Ox Alpha(100T/day 무제한급)를 무료 호출할 때:

npm i -g command-code
# 100만(1M) 토큰 컨텍스트 & 하루 100T 토큰의 넉넉한 한도
cmd --model stealth/ox-alpha

파이썬 표준 OpenAI SDK로 Groq 등 무료 엔드포인트를 호출하는 예시:

from openai import OpenAI

client = OpenAI(
    base_url="https://api.groq.com/openai/v1",  # 신용카드 불필요
    api_key="gsk_YOUR_KEY",                     # console.groq.com/keys 무료 발급
)

res = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(res.choices[0].message.content)
