🧭 Decision Models — Jev · Kev · Tev · Clef · Luna

채팅이 아니라 판정을 돌려주는 System One 모델 가이드. state + typed 질문(choice/score/noul)을 보내면 텍스트 대신 확률 분포가 돌아옵니다. 전 모델 output 무료, input $0.02~0.15/M로 가격이 아니라 컨텍스트·옵션 수·레이턴시·개방성으로 고르는 카테고리입니다.

라이브 소스: OpenRouter Decisions 카탈로그 · 스냅샷 로딩 중…

📞 호출법 2가지 (OpenRouter)

  • POST /api/alpha/decisions — Decisions API (모든 decision 모델 공용, model에 전체 ID)
  • POST /api/v1/systemone — TypeSafe SDK 호환 (System One 규격 모델: Jev·Kev·Clef·Mercury 등)
curl https://openrouter.ai/api/alpha/decisions \ -H "Authorization: Bearer $OPENROUTER_API_KEY" \ -d '{"model":"typesafe/jev-1.13", "state":{"ticket":"결제가 두 번 됐어요"}, "questions":{"refund":{"type":"noul", "instructions":"환불을 요구하는가?"}}}'
